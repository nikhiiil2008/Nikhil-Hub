# NG Board Buddy

A mobile-first static EdTech learning app for NG. Built with HTML, CSS and JavaScript; no paid API or build service required.

## Free GitHub Pages deployment
1. Open repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select branch main and folder /(root), then Save.
4. Wait for GitHub Pages to publish the site.

## Content integrity
- Current quiz items are explicitly labelled demo questions.
- No item is presented as an authentic UP Board PYQ.
- Official syllabus alignment, verified notes, diagrams and source-cited PYQs must be added after checking UPMSP materials.
- Progress, bookmarks and wrong answers are stored in localStorage on the current device.

## Features
Subject/chapter navigation, practice feedback, quiz flow, bookmarks, wrong-answer revision, local results, search, responsive mobile navigation and basic offline caching.
